# Аудит исследовательского движка 1.1

Исходная версия: commit `43226fe21c4707a777d937ca3e991cde1dbd29d1`. Проверка проведена параллельно по движку, данным и статистике, затем выполнен независимый перекрёстный просмотр и общий regression-прогон. Production PANDORA не изменяется. Улучшения ниже устраняют воспроизводимые программные ошибки; они не являются обещанием доходности или идеальной стратегии.

| Область / подтверждённая ошибка | Исправление и проверка |
|---|---|
| Price response терял каждое изменение между последним и первым тиком соседних блоков; направление могло определяться неверно | Reference — предыдущее закрытие; учитывается первый тик, interval duration и отдельный internal move. Тест с ценами 100 → 110 → 109 |
| Индивидуальный trade сравнивался с распределением средних блоков, искусственно сужающим разброс размеров | Размеры отдельных прошлых сделок образуют bounded causal baseline; средние блоков остаются отдельным признаком. Тест гетерогенного потока без ложной whale-series |
| Структурный выход позиции зависел от последнего local токена, который мог отличаться от её собственного anchor | У каждого book собственный breach streak и persistent invalidation; подтверждённый пробой не исчезает после отскока |
| Re-entry и отложенный fill могли разрешать прежнее направление после нового противоположного confirmed local | Противоположный local отменяет watch/fill; проверка выполняется на причинно доступном состоянии |
| Same-timestamp поток мог оставить отложенный вход до гораздо более позднего события | Сигнал имеет event_seq и ограниченный срок: один блок событий / gap_seconds |
| Sweep предыдущего anchor мог превратиться в false-break другого anchor | Sweep сопоставляется по local ID; старое событие не переносится на новый local |
| Инвалидированный local мог сохранять устаревший trend veto | Направление не опирается на потерявший силу защитный anchor |
| Gap не инвалидировал кандидата согласованно и сохранял OHLCV историю | Согласованные invalidated/status и очистка candle-history; сравнения через известные пропуски запрещены |
| Late/invalid события могли быть просто отброшены, оставляя видимость полноценного flow | Неизвестная непрерывность вызывает цензурирование и новый warmup; безвредные дубликаты отдельно |

| Replay пропускал часть некорректных строк, cache/fallback трактовали некоторые дефекты неоднозначно | Строгие trade/GAP schema, нормализованные SourceError, проверка OHLCV gaps и accepted coverage |
| Время получения измерялось до блокирующего recv | receive timestamp фиксируется после получения кадра |
| Trade мог приниматься до subscription ACK | Явная проверка ACK/request ID; отвергнутые подписки не прогревают стратегию |
| Сокет мог быть жив, пока один токен замолчал; его старая позиция оставалась активной | Таймер каждого символа цензурирует stale state; статус покрытия учитывает silence/stale/late |
| Отчёт выделял кандидатов из неполных/ошибочных запусков и generic unconditional labels | Выделение только из completed evaluation и действительных entry/re-entry/exit гипотез, с многодневными наблюдениями |
| IID Wilson bound использовался для выбора при коррелированных overlapping outcomes | Удалён из отбора; оставлен только явно названным справочным IID interval. Добавлены дневные описательные сводки |

Новые тесты находятся в `test_engine_audit.py`, `test_data_audit.py`, `test_output_audit.py`, `test_model_cli_audit.py`. Сохранены исходные проверки причинности, lower-low без подтверждения, per-tick MFE и repeatable replay. В старых вручную созданных fixtures исправлены два несогласованных предположения: корректная временная последовательность history перед текущим блоком и возобновление потока после gap перед инъекцией позиции. Торговые assertions не отключались.

Оставшиеся пределы исследования: фиксированная модель slippage, отсутствие order book/funding/impact, потенциальная зависимость выборок и необходимость independent walk-forward. Подтверждение Local Low/High остаётся проверяемой гипотезой. Никакой новый threshold не выбран ради красивого synthetic PnL. Реальная доступность архивов и live feed в текущей среде ограничена сетевой политикой; сетевой запрет не обходился. Six-hour session и production deploy не запускались.

## Уточнение пользователя: локалы только по часовикам

Источник Local High/Low переведён на H1. Неперекрывающиеся trade-блоки сохраняются исключительно для executed flow и price response. H1-кандидат формируется из часового экстремума относительно предыдущих закрытых часовиков и подтверждается последующим закрытым H1. Forming/current H1 не подтверждает локал. Realtime получает закрытый часовой контекст до начала аудит-сессии; исторический tape строит те же часовые свечи хронологически. Разрывы и незавершённые часы не превращаются в полноценные свечи. Это исходная формализованная гипотеза, не утверждение об оптимальном числе часов.

Проверяются future/partial H1, запрет подтверждения tick-блоком, bootstrap-to-delayed-tick causality и воспроизведение H1 seed-контекста. Отбор сигналов также различает допустимый сигнал и действительно исполненный PAPER-вход: незаполненный сигнал не проходит gate. Retrospective MISSED_REENTRY использует только исполнимую возможность после причинной eligibility и учитывает запрет fill.
