## Key result: why false locals happen

The main failure is a normal correction inside an unfinished H1 swing:

old trend -> candidate extreme -> opposite bounce -> old trend resumes -> new same-side extreme

Therefore a flow flip or MACD cross alone is not enough.

Every candidate must be invalidated immediately if price prints a new same-side extreme.

## Structural maturity

Before survival filtering, true terminal reversals generally occurred later in the active swing than the first false correction.

On the discovery portion at the 5-minute checkpoint:
- true local active-swing maturity median: ~3.26 H1 ATR
- first false candidate median: ~2.04 H1 ATR

In paired comparisons the true terminal local was structurally more mature than the first false candidate in roughly 95% of available pairs.

After 10–30 minute survival this discriminator weakens, so maturity is a candidate gate, not final confirmation.

## 1-2-3 reversal test

A causal structural pattern was replayed:

LOW:
new low -> bounce -> higher low without breaking the candidate low -> break of bounce high

HIGH is mirrored.

Result: it improved exact-local precision in some chronological blocks, but did NOT remain stable enough across all blocks to be promoted as the only trigger. It remains a useful confirmation component.

## Recommended state machine

WATCH -> FORMING -> EARLY_CONFIRM -> CONFIRMED -> HARD_CONFIRMED

Immediate rule:
NEW SAME-SIDE EXTREME -> INVALIDATE -> RESET TO WATCH

Evidence hierarchy:
1. active swing maturity relative to prior confirmed local / H1 ATR;
2. survival without a new same-side extreme;
3. retracement fraction of the whole active swing;
4. opposite-side price response;
5. new-side price/flow efficiency > old-side efficiency;
6. persistent flow transfer;
7. MACD histogram/slope confirmation;
8. OI confirmation where available;
9. L50 / liquidations only when genuinely recorded.

The engine intentionally uses staged PAPER position fractions:
- EARLY_CONFIRM: 20% of intended paper position
- CONFIRMED: 60%
- HARD_CONFIRMED: 100%

This is a research risk-control device, not a real-money leverage recommendation.

## Critical conclusion

A static one-shot rule is not yet good enough. The 30D data confirms that many false corrections can temporarily look like terminal reversals.

The practical solution is sequential evidence + immediate invalidation + staged exposure. The ~0.38% early-entry distance is reproducible on true locals, but preserving that timing while eliminating false first signals remains the key optimization problem.

Do not promote to live trading until walk-forward first-signal precision, false-local rate, MAE and swing capture pass a declared OOS gate.
